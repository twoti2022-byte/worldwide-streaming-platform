# Worldwide Streaming Platform

Module 01 establishes the engineering baseline for a future worldwide streaming platform. It includes a Next.js, React, and TypeScript app shell; Supabase boundaries; identity and role migrations; API conventions; security headers; logging; tests; and documentation.

## Stack

- Next.js, React, TypeScript
- Supabase Auth and PostgreSQL
- Vercel-ready deployment
- Future server-side OpenAI and Cloudflare Stream boundaries

## Local setup

1. Copy `.env.example` to `.env.local` and provide safe local values.
2. Run `npm install`.
3. Run `npm run dev`.

## Module rules

Module 01 does not implement catalogs, playback, payments, recommendations, rights workflows, or production ChatGPT features. Discovery is not permission to publish copyrighted content.
