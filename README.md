# Worldwide Streaming Platform

Module 01 establishes a Next.js, React, TypeScript, Supabase, and Vercel-ready foundation for a future worldwide entertainment platform.

> Stories from everywhere. Discover what speaks to you.

## Stack

- Frontend: Next.js, React, TypeScript
- Database/auth: Supabase PostgreSQL and Supabase Auth
- Deployment: Vercel-ready
- Future video: Cloudflare Stream boundary only
- Future ChatGPT: OpenAI API through secure server-side services only

## Local setup

1. Install packages with `npm install`.
2. Copy `.env.example` to `.env.local` and provide real local Supabase values.
3. Run `npm run dev`.
4. Run `npm run lint`, `npm run typecheck`, `npm run test`, and `npm run build` before submitting changes.

## Module 01 scope

This module includes only the public shell, environment validation, Supabase boundaries, foundational identity migrations, authorization primitives, safe error/logging conventions, reusable UI primitives, and future service boundaries.
