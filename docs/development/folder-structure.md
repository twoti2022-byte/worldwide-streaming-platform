# Folder Structure

- `app/` — Next.js app routes and API routes.
- `components/` — reusable UI, layout, and shared components.
- `lib/` — configuration, Supabase clients, API primitives, security, logging, validation, and authorization.
- `services/` — future service boundaries for auth, users, content, video, and ChatGPT.
- `supabase/` — migrations and seed notes.
- `tests/` — unit and integration tests.
