# API namespaces

Module 01 implements `/api/health` and `/api/auth/session`. Future namespaces may include `/api/users`, `/api/content`, `/api/movies`, `/api/series`, `/api/search`, `/api/chatgpt`, `/api/video`, `/api/creators`, `/api/rights`, `/api/notifications`, `/api/analytics`, and `/api/payments` after explicit module approval.
